ZAKYNTHOS PACKLISTE – iPhone-PWA
================================

Diese Version enthält keine konkreten Reisedaten, Flugzeiten, persönlichen Namen, Adressen oder Buchungsnummern. Sie enthält eine allgemeine Packliste für eine Reise nach Zakynthos.

DATEIEN
- index.html: die App
- manifest.webmanifest: Installations-Metadaten
- sw.js: Offline-Caching nach dem ersten Laden
- icons/: App-Symbole für iPhone und PWA

ÖFFENTLICH HOSTEN UND AUF DEM IPHONE INSTALLIEREN
1. Lege ein öffentliches Repository an (z. B. auf GitHub).
2. Lade alle Dateien und den Ordner icons in das Hauptverzeichnis hoch.
3. Aktiviere unter Settings → Pages die Veröffentlichung aus dem main-Branch und dem Root-Verzeichnis.
4. Öffne die bereitgestellte HTTPS-Adresse in Safari auf dem iPhone.
5. Tippe auf Teilen → Zum Home-Bildschirm → Hinzufügen.

DATENSCHUTZ-HINWEISE
- Der eingebaute Standardinhalt enthält keine konkreten Reisedaten oder Buchungsdetails.
- Eigene Änderungen und Packlisten-Haken werden lokal im Browser gespeichert und nicht automatisch an einen Server übertragen.
- Wenn du eigene Einträge hinzufügst, vermeide persönliche Daten wie Namen, Adressen, Telefonnummern, Buchungsreferenzen oder genaue Reisezeiten, wenn die öffentliche Version weiterhin öffentlich bleiben soll.
- Die Website selbst ist öffentlich erreichbar, sobald du sie öffentlich hostest.
